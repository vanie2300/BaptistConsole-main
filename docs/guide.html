Console tabs

KeyAction

Bible Presenter

ActionHow
Pick a verse Select Book → Chapter → Verse in the left panel.
Reference search Type e.g. John 3:16 into the search bar and press Enter.
Keyword search Open the search dropdown, choose Keyword, pick a scope (Whole Bible / Current Book), enter the term, click Go.
Clear search Clear Search in the dropdown, or press Esc.
Project a verse Click Display Verse to open the projector. In the Display dropdown, tick the screens to use (shown by name or size; primary has a badge), or choose All Displays. A check on Auto targets the primary-configurable display.
Toggle reference on screen Settings → Bible Presenter → Show Verse Reference.
Show psalm headings Settings → Bible Presenter → Show Psalm Titles — the psalm note (e.g. "A Psalm of David") appears above verse 1 in a smaller, muted style.

Search results highlight matching terms, and the matched book/chapter/verse is selected and auto-scrolled in the list.

Hymn Presenter

ActionHow
Find a hymn Type in the search box — matching titles are filtered and the search term is highlighted.
Select a hymn Click a row — slides render in the center preview with upcoming thumbnails on the right.
Navigate slides ← / → arrow keys (when not typing) or the on-screen buttons.
Present Click Present to open the projection window. In the Display dropdown, tick the screens to use (name or size; primary has a badge), or choose All Displays. A check on Auto targets the primary-configurable display.
Add a hymn + Add Hymn → fill title, verses, optional chorus → Save Hymn (persists to hymns.json).
Delete a hymn Select it and click Delete Hymn.

Presenter window

  • Opens focused, filling the full bounds of the selected display.
  • Windows are normal — use native Alt+Tab to switch between the projection, PowerPoint, and the console.
  • Esc (while the console or a presenter has focus) closes presentation windows.
  • Minimizing or hiding a presenter window closes it (by design).
Tip: the presenter status light in the console turns green and pulses "Live" whenever a projection window is open.

Keyboard shortcuts

Shortcuts that work while the console has focus, grouped by context.

ShortcutContextAction
1 / 2 Console Switch to Bible / Hymns tab
← / → Hymns (not typing) Previous / next slide
Enter Hymns (not typing) Start presentation
Esc Console Close settings modal / search dropdown; close all presentation windows
Esc Presenter window Close that presentation window
Ctrl+R Dev Reload (use after renderer edits during development)
Note: arrow-key and Enter navigation in Hymns is ignored while typing in an input, textarea, select, or while the Add Hymn modal is open.

Settings

Open via the Settings button in the top bar. Changes apply on Apply Settings; Reset to Defaults restores factory settings. Toast notifications confirm both actions.

Theme

ControlDescription
Dark / Light theme Applies app-wide to the console interface.
Presenter Colors Background, text color, weight, and font for all projections.
Live preview Shows how a verse will look as you change colors, fonts, and images.

Bible Presenter

SettingDescription
Max Font Size Upper ceiling (px) for the projected verse auto-fit. Range 100–800px.
Reference Size Scale (50–200%) for the projected verse reference. Default 100%.
Show Verse Reference Toggle the reference display above the projected verse text.
Projected Text Size Scale (70–155%) for the projected verse auto-fit. Default 130%.
Show Psalm Titles Toggle psalm headings above verse 1 in a smaller, muted style.
Background Image Image plus opacity for the Bible projector background.

Hymn Presenter

SettingDescription
Text Alignment Left / Center / Right.
Text Layout Full or Compact (70% width).
Show Verse Numbers Toggle "Verse N" labels.
Title Size Default title font size (vw).
Slide Font Size Scale the auto-fitted lyrics (base 7 = fitted size; 14 = twice as big). Growth beyond the screen edge is clipped.
Transition Slide transition type.
Background Image Image plus opacity for the Hymn projector background.
Note: reference size on the projected display uses calc(clamp(0.9rem, 1.8vw, 1.6rem) × n/100), so 100% equals the default size, above 100% is larger, below is smaller.
