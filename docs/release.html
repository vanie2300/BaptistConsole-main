Release Notes

What ships in the very first release of Baptist Console.

v1.0.0 — First Release

NewNew: standing up the core product for worship use.

Highlights

  • Bible Presenter — full KJV 1611 navigation, reference and keyword search, one-click projection with auto-fit text and configurable reference size.
  • Hymn Presenter — searchable hymn library (hymns.json), slide preview with upcoming thumbnails, add/delete hymns, arrow-key navigation.
  • Presentation — projectors open on the selected display as normal windows (Alt+Tab friendly), Esc closes, and a green "Live" indicator confirms projection.
  • Settings — dark/light theme, projected colors/fonts, per-module background images, text sizing and layout controls with a live preview.

Fixes & design decisions in this release

  • Background isolation — Bible and Hymn projectors each keep an independent background image. Any legacy shared key left by a pre-release build is migrated and removed.
  • Readable titles — hymn titles auto-fit down to a 4 vw floor with overflow scrolling instead of clipping.
  • Independent reference size — the projected verse reference has its own scale setting (50–200%), decoupled from verse auto-fit.
  • Search visibility — search match highlight colors are defined in both presenters so highlights are always visible.
  • No always-on-top — presenter windows are normal windows; PowerPoint and other apps can be reached with Alt+Tab at any time.

Known limitations

  • Reinstalling (or later updating) the app can overwrite hymns.json — back it up before reinstalling.
  • Windows only for the NSIS installer; Linux ships as an AppImage. macOS is not a release target yet.
