Why does my Bible projector show a Hymn background?

Since v1.0.0 the Bible and Hymn presenters each keep their own background image. If a pre-release build had set one shared image, it is copied to both modules once and the old key is removed.

Fix: open Settings → Bible Presenter (or Hymn Presenter) → Background Image, and clear or reset the image once. From then on, the two modules stay independent.

Why can't I switch to PowerPoint while presenting?

Presenter windows in v1.0.0 are normal windows (never always-on-top), so nothing blocks switching apps.

Fix: use Alt+Tab to switch freely while a presenter is open.

Why does a long hymn title shrink a lot?

Titles auto-fit: the size is reduced (in 0.25 vw steps) while the title overflows width or height, down to a 4 vw floor. It only shrinks as much as needed to keep the title readable and unclipped.

Tip: very long titles naturally get capped at the floor — consider shortening the title if it must stay large.

The projected verse reference is too small — how do I enlarge it?

Use Settings → Bible Presenter → Reference Size. It scales from 50–200% (default 100%). Reference size is independent of the verse text auto-fit, so it won't fight the verse font.

Why is my verse reference not showing?

Check Settings → Bible Presenter → Show Verse Reference. When disabled, the reference is hidden on the projection (and greyed out in the settings preview). Enable it and click Apply Settings.

Text looks blurry or clipped on the projector

  • Blurry — make sure the presenter window is opened on its intended full display via the display picker; a resized/non-native window can soften text.
  • Clipped — with a fixed preview frame the hymn center panel scrolls instead of clipping when content overflows the frame. On the projection itself, auto-fit keeps text inside bounds.

My added hymns disappeared after reinstalling the app

The hymn library lives in hymns/hymns.json. In packaged builds this file sits inside the app's resources (process.resourcesPath/hymns/hymns.json). Reinstalling the app can overwrite it.

Fix: back up hymns.json before reinstalling, and restore it afterwards.

The presenter opens on the wrong display

Presenters open on the display you selected in the module's display picker (falls back to the primary display if unset). Re-pick the display and try again. If a monitor was unplugged/rearranged, ids change — pick the display once more.

Do I need Node.js/npm to run the app?

Only for development: npm install then npm start. End users install the packaged .exe (from npm run build:win) which bundles everything — no Node.js required.
