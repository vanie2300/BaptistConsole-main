Settings

Open via the Settings button in the top bar. Changes apply on Apply Settings; Reset to Defaults restores factory settings. Toast notifications confirm both actions.

Theme

ControlDescription
Dark / Light theme Applies app-wide to the console interface.
Presenter Colors Background, text color, weight, and font for all projections.
Live preview Shows how a verse will look as you change colors, fonts, and images.

Bible Presenter

SettingDescription
Max Font Size Upper ceiling (px) for the projected verse auto-fit. Range 100–800px.
Reference Size Scale (50–200%) for the projected verse reference. Default 100%.
Show Verse Reference Toggle the reference display above the projected verse text.
Background Image Image plus opacity for the Bible projector background.

Hymn Presenter

SettingDescription
Text Alignment Left / Center / Right.
Text Layout Full or Compact (70% width).
Show Verse Numbers Toggle "Verse N" labels.
Title Size Default title font size (vw).
Transition Slide transition type.
Background Image Image plus opacity for the Hymn projector background.
Note: reference size on the projected display uses calc(clamp(0.9rem, 1.8vw, 1.6rem) × n/100), so 100% equals the default size, above 100% is larger, below is smaller.
