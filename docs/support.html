Support Baptist Console

Baptist Console is a free, open-source project (MIT licensed) built to help churches project Bible verses and hymns during worship services. If it helps your church, here are ways to keep it going.

Free forever. There is no subscription, no license fee, and no premium tier. Community support keeps the project alive.

Financial support

Even a small one-time gift helps cover hosting, tooling, testing devices, and development time. Choose whatever works for you.

GCash (Philippines)

Send a donation straight to the developer's GCash wallet — any amount is appreciated and goes toward hosting, tooling, and testing hardware.

Non-financial support

Every bit helps, even without money. These cost nothing but make a real difference.

Star the repository

Stars raise visibility and tell the developer the project matters to real churches.

Report bugs & request features

Found a problem or want a feature? Open an issue with clear steps so it can be fixed quickly.

Contribute code or docs

It's a small, vanilla HTML/CSS/JS codebase — easy to read and easy to contribute to. Docs always need proofreading too.

Translate or share

Add or improve translations, or share Baptist Console with other churches, pastors, and worship teams.
