Baptist Console

A church presentation suite for projecting Bible verses and hymns during worship services. Built with Electron and vanilla HTML/CSS/JS.

v1.0.0 — First Release Electron 33 Windows & Linux MIT License

Read the user guide Release notes

Getting started

Make sure Node.js (LTS recommended) is installed, then:

npm install
npm start

Build installers:

npm run build:win     # Windows NSIS installer → dist/
npm run build:linux   # Linux AppImage → dist/

Features

Bible Presenter

  • Browse books, chapters, and verses (KJV 1611).
  • Reference search (John 3:16) and keyword search across the whole Bible or the current book.
  • Search matches highlighted in results.
  • Project verses to a secondary display with auto-fit text and a configurable max size.

Hymn Presenter

  • Search, add, and delete hymns from a hymns.json library.
  • Live preview of current / next slides plus upcoming thumbnails.
  • Auto-fit verse text and titles with readable floors.
  • Project slides to a secondary display.

Settings

  • Dark / light theme, presenter colors & fonts.
  • Per-module background images and display toggles.
  • Text-sizing controls with a live preview.
  • Toast notifications confirm saves and resets.

Presentation

  • Presenter opens on the configured display, filling its bounds.
  • Normal windows — switch apps with Alt+Tab.
  • Green pulsing Live indicator when projecting.
  • Esc closes presentation windows.
